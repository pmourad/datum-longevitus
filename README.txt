DATUM LONGEVITUS — LANDING PAGE
================================

HOW TO VIEW
Double-click index.html to open it in any modern browser (Chrome, Safari, Firefox, Edge).
No installation, build step or internet connection is needed: all images, logos and
fonts are included in the assets folder.

WHAT'S INSIDE
index.html            The full page: markup, styles and all animation code in one file
assets/               Photos, slideshow images and logo files
assets/fonts/         Inter Tight and IBM Plex Mono (self-hosted, SIL Open Font License)

FEATURES
- Interactive point-grid hero that reacts to the mouse, with glow and data/glitch animation
- Scroll-triggered entrance animations and parallax (works in all current browsers)
- Animated network backgrounds, logo-style growth animation in "The Name"
- Photo slideshow behind "What we do"
- Sticky header with smooth-scrolling anchor links and a hamburger menu on smaller screens
- Fully responsive: desktop, tablet and mobile layouts
- Respects the visitor's "reduce motion" system setting

TO PUBLISH ONLINE
Upload the whole folder (index.html + assets) to any static host — e.g. Netlify,
Vercel, GitHub Pages, or the web server of your existing site. Keep the folder
structure as it is.

NOTES FOR DEVELOPERS
- The "Book a call" / "Book a consultation" buttons and the newsletter form are
  placeholders; connect them to the booking tool and mailing list provider.
- Footer and anchor links point to sections on this page (#stories, #about,
  #protect, #name, #testimonials, #contact).
